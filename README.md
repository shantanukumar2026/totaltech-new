# Total Tech - Enterprise Technology & Industrial Systems

Official web portal and technology portfolio showcase for Total Tech.

## Core Capabilities & Portfolios

- **Manufacturing Technology**: Autonomous robotics workcells, additive sand printing, precision CNC, and process automation.
- **Artificial Intelligence**: Cognitive neural processing engines, high-throughput predictive telemetry, and real-time optical computer vision inspection.
- **Quantum Technology**: Distributed planetary compute grid architectures and quantum algorithm simulations.
- **Information Technology**: Scalable enterprise datacenter server fabrics and zero-trust cybersecurity defense infrastructure.
- **Machine Learning**: Edge micro-sensor telemetry, hardware anomaly diagnostics, and demand yield forecasting pipelines.

## Technology Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Runtime**: React 19
- **Styling**: Tailwind CSS v4 & Custom Design Tokens
- **Icons**: Lucide React
- **Typography**: Manrope & Geist (Google Fonts via `next/font`)

## Getting Started

### Prerequisites

- Node.js 20.x or higher
- npm 10.x or higher

### Installation & Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Navigate to `http://localhost:3000` to view the application.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Run production server
npm run start
```
